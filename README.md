## Still to fill in (top of the `<script>` in index.html)

- `PHONE` — 10-digit number. Empty keeps the Call and WhatsApp buttons hidden.
- `SOCIAL` — Instagram / Facebook URLs. Empty hides the icon; all empty hides "Follow us".
- `GBP_REVIEW` — the owner's official `g.page/r/.../review` short link (Google Business Profile →
  Ask for reviews). Best option on phones; the page works without it.
